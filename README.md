# BullConvert — конвертер файлов

Сайт: откройте ссылку на GitHub Pages этого репозитория (Settings → Pages).

Всё работает **прямо в браузере на вашем устройстве** — файлы никуда не загружаются.
Сайт можно установить как приложение (телефон, планшет, компьютер) и пользоваться **без интернета**:
«Настройки» → «Подготовить к работе без интернета».

## Что умеет

- **PDF:** объединить, разделить, удалить/повернуть/переставить страницы, сжать, вставить текст и подпись, номера страниц и водяной знак, пароль (AES-256), PDF → Excel,
  скрыть данные с настоящим удалением из файла (а не закрашиванием).
- **Документы:** DOCX, RTF, ODT, PDF, TXT, Markdown, HTML, DjVu → PDF, DOCX, JPG, PNG, EPUB, FB2, HTML, Markdown, TXT; PowerPoint (PPTX) → слайды PDF и JPG, DOCX, TXT; старые Word (DOC) и PowerPoint (PPT) → PDF, DOCX, TXT, HTML — без Microsoft Office; правка текста перед конвертацией; PDF → Word с абзацами, заголовками и картинками.
- **Распознавание текста:** сканы PDF/DjVu и фото/скриншоты → TXT, DOCX (русский и английский).
- **Книги:** EPUB, FB2, MOBI, AZW → PDF, DOCX, EPUB, FB2, TXT.
- **Фото:** HEIC, TIFF, PNG, JPG, WEBP, BMP, GIF, SVG, AVIF → PNG, JPG, WEBP, PDF, GIF, TIFF, BMP, ICO; обрезка, поворот, сжатие до нужного размера, удаление фона, склейка.
- **Таблицы и XML:** XLSX, CSV, JSON, XML, YAML (все листы) → PDF, Word, Excel и друг в друга.
- **Аудио/видео:** MP3, WAV, OGG, M4A, FLAC, MP4, WEBM, MOV → MP3, WAV, MP4, WEBM, GIF, кадры JPG; обрезка по времени.
- **Удобство:** история конвертаций, «Поделиться» с телефона, упаковка в ZIP, английский интерфейс.
- **Архивы:** ZIP, папки целиком.
