Политика конфиденциальности

Редакция от 20 ноября 2026 г.

1. Общие положения

1.1. Настоящая Политика определяет порядок обработки данных при использовании веб-приложения BullConvert, размещённого по адресу https://player-hockey.github.io/bullconvert/, включая установленную с этого адреса версию приложения (далее — Приложение).

1.2. Владелец Приложения (далее — Владелец) обеспечивает его работу и отвечает на обращения по вопросам обработки данных.

1.3. Использование Приложения означает согласие с настоящей Политикой. При несогласии с Политикой Пользователь должен прекратить использование Приложения.

2. Обработка файлов

2.1. Файлы Пользователя обрабатываются программными средствами Приложения непосредственно в браузере на устройстве Пользователя.

2.2. Файлы, их содержимое и имена не передаются Владельцу и третьим лицам, за исключением случая, указанного в разделе 5.

2.3. Результаты обработки создаются на устройстве Пользователя и сохраняются средствами браузера.

3. Данные, хранящиеся на устройстве Пользователя

3.1. Приложение сохраняет в хранилище браузера на устройстве Пользователя:

  • историю обработанных файлов (результаты последних конвертаций);
  • настройки Приложения (качество, язык интерфейса, шаблон имени, выбранные форматы);
  • изображение подписи — только при выборе Пользователем параметра «запомнить на этом устройстве»;
  • программные модули, шрифты и словари для работы без подключения к интернету.

3.2. Указанные данные не передаются Владельцу.

3.3. Пользователь вправе удалить их в любое время: история — кнопкой «История» → «Очистить историю»; остальные данные — очисткой данных сайта в настройках браузера или удалением Приложения.

4. Сторонние сервисы

4.1. Для работы Приложения браузер Пользователя обращается к следующим сервисам:

СервисНазначение
GitHub Pages (GitHub, Inc.)Размещение Приложения
jsDelivrЗагрузка программных библиотек и шрифтов
djvu.js.orgМодуль обработки файлов DjVu
staticimgly.com (IMG.LY)Модель удаления фона изображений
Google (браузер Chrome)Загрузка языковой модели для перевода документов

4.2. При таких обращениях сервисам становятся доступны технические сведения: IP-адрес, сведения о браузере, дата и время запроса. Файлы Пользователя этим сервисам не передаются.

4.3. Обработка данных указанными сервисами регулируется их собственными политиками, в том числе заявлением GitHub о конфиденциальности.

5. Обработка на компьютере Владельца

5.1. Обработка отдельных форматов (чертежи КОМПАС-3D, документы через Microsoft Office, архивы RAR и 7Z) выполняется на компьютере Владельца. Эта возможность доступна только по отдельному адресу, предоставленному Владельцем, и недоступна на публичном адресе Приложения.

5.2. При использовании этой возможности:

  • файлы указанных форматов передаются на компьютер Владельца, помещаются во временную папку и удаляются автоматически после обработки;
  • для предоставления доступа Владельцу передаются: указанное Пользователем имя устройства, сведения о браузере, IP-адрес, страна (при её определении), дата запроса. Сведения хранятся на компьютере Владельца до удаления устройства из списка доступа;
  • в браузере Пользователя сохраняется файл cookie bc_token сроком на 1 год, используемый исключительно для подтверждения выданного доступа;
  • при доступе через интернет данные передаются по защищённому соединению (HTTPS) через сервис туннелирования (localhost.run или Cloudflare), который технически участвует в их передаче.

6. Обязательства Владельца

6.1. Владелец не собирает и не хранит файлы Пользователей, не требует регистрации и предоставления персональных данных, не использует рекламные сервисы, системы аналитики и сторонние файлы cookie.

6.2. Владелец не продаёт и не передаёт данные Пользователей третьим лицам, за исключением случаев, предусмотренных законодательством.

7. Права Пользователя

7.1. Пользователь вправе получить сведения о данных, хранящихся у Владельца в соответствии с разделом 5, и потребовать их удаления.

7.2. Обращения направляются через раздел обсуждений проекта: https://github.com/Player-hockey/bullconvert/issues.

8. Изменение Политики

8.1. Владелец вправе изменять настоящую Политику. Новая редакция вступает в силу с момента её публикации на данной странице.
