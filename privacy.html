Политика конфиденциальности

Редакция от 20 ноября 2026 года

Коротко. BullConvert конвертирует файлы прямо в вашем браузере. Ваши файлы никуда не отправляются, владелец сайта их не получает и не видит. Регистрации, рекламы, счётчиков посещений и сторонних cookie нет. Всё, что сайт сохраняет (историю, настройки, подпись), хранится только на вашем устройстве, и вы можете это удалить.

1. О чём эта политика

Эта политика описывает, какие данные обрабатываются при использовании веб-приложения BullConvert (сайт player-hockey.github.io/bullconvert и установленное с него приложение), где они хранятся и как их удалить.

Сайт поддерживает его владелец (далее — «владелец»). Вопросы о данных можно задать через раздел обсуждений проекта: github.com/Player-hockey/bullconvert/issues.

2. Ваши файлы

  • Файлы, которые вы добавляете, читаются и конвертируются программой внутри вашего браузера. Они не загружаются на сервер владельца или третьих лиц.
  • Результаты конвертации создаются на вашем устройстве и скачиваются из браузера напрямую.
  • Владелец не имеет доступа к содержимому, именам и количеству ваших файлов.
  • Распознавание текста, удаление фона, перевод документов и другие функции тоже работают на устройстве.

3. Что хранится на вашем устройстве

Чтобы приложением было удобно пользоваться, браузер сохраняет следующее. Эти данные не передаются владельцу.

4. Что видят технические сервисы

Сам сайт и его программные модули загружаются из интернета. При этом ваш браузер, как при открытии любого сайта, сообщает этим сервисам технические сведения: IP-адрес, тип браузера и время запроса. Содержимое ваших файлов им не передаётся.

  • GitHub Pages (GitHub, Inc.) — размещение сайта. Обработка данных — по заявлению GitHub о конфиденциальности.
  • jsDelivr — загрузка программных библиотек и шрифтов, когда они понадобятся.
  • djvu.js.org — модуль для файлов DjVu, загружается только при работе с ними.
  • staticimgly.com (IMG.LY) — модель для удаления фона, загружается только при использовании этой функции.
  • Google Chrome — при первом переводе документа браузер может скачать словарь от Google. Сам перевод выполняется на устройстве.

Модули скачиваются один раз и сохраняются в браузере. После этого приложение работает без интернета.

5. Что владелец не делает

  • Не собирает и не хранит ваши файлы, их содержимое и имена.
  • Не требует регистрации, имени, телефона или электронной почты.
  • Не использует рекламу, системы аналитики, счётчики посещений и сторонние cookie.
  • Не продаёт и не передаёт ваши данные третьим лицам.

6. Подключение к компьютеру владельца

Некоторые форматы (чертежи КОМПАС-3D, точная конвертация через Microsoft Office, архивы RAR и 7Z) обрабатываются программами на компьютере владельца. Эти функции доступны только если вы открываете BullConvert по отдельному адресу, который вам дал владелец. На публичном сайте их нет.

При таком подключении:

  • Файлы этих форматов передаются на компьютер владельца для обработки. Они сохраняются во временной папке и автоматически удаляются после конвертации (оставшиеся копии удаляются при следующих конвертациях).
  • Чтобы дать доступ, владелец видит запрос: введённое вами имя устройства, тип браузера, IP-адрес и страну (если она определена), дату запроса. Эти сведения хранятся на компьютере владельца, пока он не удалит устройство из списка.
  • В браузере сохраняется cookie доступа (bc_token) на 1 год. Он нужен только для того, чтобы не запрашивать разрешение повторно.
  • При доступе через интернет данные идут через защищённое соединение (HTTPS) сервиса туннелей (localhost.run или Cloudflare). Этот сервис технически обрабатывает передаваемые данные.

Чтобы удалить свои сведения, попросите владельца удалить устройство из списка доступа и очистите данные сайта в браузере.

7. Ваши права

На публичном сайте владелец не получает ваших персональных данных, поэтому удалять у себя ему нечего. Всё сохранённое находится у вас на устройстве. При подключении к компьютеру владельца вы можете в любой момент узнать, какие сведения о вашем устройстве хранятся, и потребовать их удаления, связавшись с владельцем.

8. Дети

Сайт не собирает данные пользователей и может использоваться без ограничений по возрасту.

9. Изменения

При изменении работы приложения политика будет обновлена. Дата редакции указана в начале страницы. Новая редакция действует с момента публикации.
