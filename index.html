BullConvert

⚙ Администратор

Документы, PDF, книги, DjVu, фото, таблицы, аудио, видео, архивы, чертежи КОМПАС и AutoCAD. Конвертация идёт прямо на вашем устройстве — файлы никуда не загружаются, работает и без интернета.

Настройки
Без интернета Скачает все модули один раз (≈35 МБ), дальше конвертер работает офлайн.

    Что умеет

    Инструменты PDF

    Объединить PDF и картинки, разделить, удалить/повернуть/переставить страницы, вставить текст и подпись, скрыть данные — с настоящим удалением из файла, а не закрашиванием

    КОМПАС-3D и AutoCAD

    Чертежи CDW, FRW → PDF, DWG, DXF, PNG, JPG; спецификации SPW → PDF; модели M3D, A3D → STEP, STL, IGES, PNG, PDF; DWG, DXF → PDF, CDW, PNG. Нужен установленный КОМПАС-3D.

    Резервные копии .BAK

    Копии КОМПАС и AutoCAD: формат определяется по содержимому, дальше — как обычный чертёж или модель

    PDF и DjVu

    PDF → DOCX, TXT, EPUB, FB2, PNG, JPG; DjVu → PDF, PNG, JPG, DOCX, TXT. Сканы распознаются (русский и английский)

    Электронные книги

    EPUB, FB2, MOBI, AZW, PRC → PDF, DOCX, EPUB, FB2, TXT, HTML

    Документы

    DOCX, TXT, Markdown, HTML (любая кодировка, в т.ч. старая Windows-1251) → PDF, DOCX, EPUB, FB2, HTML, Markdown, TXT

    Фото

    HEIC/HEIF с iPhone, PNG, JPG, WEBP, BMP, GIF, SVG, ICO, AVIF → PNG, JPG, WEBP, PDF, BMP, ICO

    Таблицы и данные

    CSV, TSV, JSON, XLSX, XLS, ODS, XML, YAML → XLSX, CSV, TSV, JSON, YAML, XML, HTML, Markdown

    Аудио и видео

    MP3, WAV, OGG, M4A, FLAC, MP4, WEBM, MOV → MP3, WAV; видео → WEBM (в реальном времени)

    Архивы и папки

    ZIP, RAR, 7Z, TAR, GZ и целые папки — распаковываются, всё внутри сразу готово к конвертации. Файлы без расширения определяются по содержимому
